## 已确认需求与设计

- 第一阶段保障 Windows 与 macOS；Linux 后续逐步补齐，不列入此次交付验收。
- 同进程创建独立透明歌词窗口，置顶、无普通边框、不新增任务栏或应用切换条目；主窗口隐藏时继续显示。
- 中文歌只显示当前句；外语歌显示当前句与翻译，翻译字号较小。
- 使用整字/整词逐渐变亮，不使用字内扫色。
- 悬停工具栏包含上一首、播放/暂停、下一首，以及字号、锁定和关闭。
- 解锁后悬停显示工具栏与轻薄底板；锁定后整窗鼠标穿透，经托盘或主界面解锁。
- 首次位于屏幕下方居中、工作区内；可拖动、调整宽度，记住位置。
- 原文默认约 32 DIP，翻译约 20 DIP，居中排列、字号可调；中文单行保留相同原文字号。
- 使用 Radix UI Colors 中性色和透明度 token，配合细描边及轻微阴影；长句自然换行。
- 切句短暂淡入淡出；工具栏位于歌词上方，显隐不挤动歌词。

## 实施默认与待核实项

以下是实施建议，与用户明确确认的需求分开保存；若出现实质性体验取舍，再讨论。

- 无翻译时仅显示当前句；不以“下一句”替代翻译。
- 无真实逐字时间的 LRC 使用整句高亮，与当前主窗口歌词页保持一致；不把 SpreadWords 的估算视为真实演唱时间。
- 未开启桌面歌词时保持关闭；首次不主动打断当前应用。关闭歌词窗口只关闭该功能。
- 加载、无歌词和前奏使用低干扰表现；未播放时不保留上一首歌词。间奏/曲终按行结束时间处理，具体淡出时机在 P2 选定并记录。
- 原文驱动逐字动画，翻译保持稳定显示；没有必要为翻译估算逐字时间。
- 先核查既有可信语言元数据，再决定中文歌词判定；不能仅凭“包含汉字”判为中文。至少覆盖日语汉字、中文夹英文、无法确定语言的情况。若现有数据不足，记录局限并采用最小可解释规则，不引入语言识别服务或大依赖。
- Panel 的全屏应用、虚拟桌面行为以实机验收为准；暂不增加全屏覆盖策略设置或独立原生窗口后端。

### 任务栏实现的具体边界

- Windows 11 将窗口挂到 Shell_TrayWnd 或目标副屏任务栏；Windows 10 查找 ReBarWindow32 / WorkerW 等容器。它不是单纯在任务栏上方放一个置顶浮窗，也不需要向 Explorer 注入代码。
- Windows 10 的避让还会缩短 Explorer 的任务列表；Windows 11 使用 UI Automation 采集交互元素位置，配合窗口事件和后台查询更新空位。这两条路径应分别评估，不能从其中一条推定另一条兼容。
- 当前源码在空位未知或不足时回退固定配置矩形，可能遮挡图标。候选方案建议此时隐藏歌词，恢复可靠空位后再显示；不直接照搬其回退行为。该产品取舍尚待确认。
- 源项目记录过：跨屏重挂、Explorer 任务栏重建、退出嵌入回到悬浮窗时，既有 WPF layered HWND 的合成表面无法恢复，因而重建歌词窗口。这是源项目的已记录现象，不是已证明的 MyGo 缺陷。
- 当前 MyGo v0.7.4 有 NativeHandle 和 RunOnMain，可作为调用 Win32 的入口；WindowOptions.Parent 是 MyGo 窗口关系，不等于支持任意 Explorer HWND。跨进程父子关系、DPI、坐标、透明合成、销毁和恢复都需单独核实，不能以拿到句柄就判定接入成功。
- 源项目监听 TaskbarCreated 等消息并处理任务栏子窗口遮挡。若后续实现，隔离在 Windows 文件内；原型先证明渲染和生命周期，出现实际缺口后再讨论所需兼容代码，不先复制全部 hook、轮询和恢复框架。
- 参考仓库根许可证为 MIT；实际移植代码时保留相关版权与许可文本，另核查被复制的第三方资源。本轮未复制其代码或素材。
