# 桌面音频 PR 说明草稿

以下标题和正文可用于提交 Lilt 项目的 Pull Request。若提交给 MyGo 框架本身，
应将 `vendor/github.com/egoist/mygo/audio` 的改动映射为上游 `audio` 目录，保留
API、平台策略和测试，将 Lilt 调用层配置作为使用示例。

## 背景与问题
此前桌面端在播放音乐时，音频输出固定重采样至 `48000 Hz`，存在以下体验问题：
1. **无法跟随音源采样率**：切换不同采样率的歌曲时，受限于底层设备 5 秒空闲保留机制，音频设备不会立即按新采样率重开。
2. **切频或唤醒时容易吞字/丢开头**：在外部 DAC 切换硬件采样率、或长时间暂停（设备休眠关闭）后恢复播放的瞬间，若立即推送音乐采样，容易因硬件锁相环（PLL）尚未锁定而丢失歌曲开头的声音。

## 主要改动

### 1. 动态跟随音源采样率
- **按需切换采样率**：在每次开始播放、恢复播放以及打开音频设备时，根据音源的实际采样率配置输出设备。若切歌时采样率发生变化，立即关闭旧会话并以新采样率重开设备，无需等待 5 秒空闲超时。
- **同采样率跳过插值**：当音源采样率与输出采样率一致且为 1.0 倍速播放时，混音器直接跳过重采样插值（1:1 步进）。
- **时序与进度同步**：设备缓冲区大小、播放进度延迟补偿（40ms / 250ms）以及 5ms 防爆音音量渐变（Ramp）均改为按当前实际输出采样率动态计算，确保歌词与进度条同步。

### 2. 新增 200ms 硬件静音预热（Pre-roll Silence）
- 新增 `Player.SetPreRoll(bool)` 接口（默认关闭），Lilt 主音乐流通过 `SetPrimary(true).SetPreRoll(true)` 显式启用。
- **触发时机**：播放新歌、从头重播、切频重连设备，以及长时间暂停（>5 秒导致设备关闭）后恢复播放时，先以目标采样率打开设备，再向后端推送 200ms 的全零静音帧，随后才开始输出实际音频。
- **零进度损耗与短暂停豁免**：静音预热期间不消费音源帧、不推进播放进度（`Position`）。若仅短暂暂停（<5 秒，设备未关闭且采样率未变），则不触发 200ms 预热，直接通过 5ms 音量渐变立即恢复。普通 UI 音效默认不开启预热，无额外延迟。

### 3. 跨平台策略隔离
- **桌面端启用**：通过构建约束（Build Constraints）仅在受支持的 **Windows、macOS、Linux** 桌面后端启用动态采样率与静音预热。
- **移动端与 Web 端保持原状**：显式排除 Android 与 iOS，Web 与移动平台仍保持固定 `48000 Hz` 且无硬件预热；Web 端恢复单个 `AudioContext` 复用机制，避免切歌时重复创建上下文。

### 4. 混音行为与已知限制说明
- **共享流预热协同**：由于采用共享输出流，主音乐流触发 200ms 预热期间，其他叠加声音也会同步等待剩余静音帧；普通音效不会重新触发或延长预热。当最后一个启用预热的播放器关闭、暂停、停止或禁用预热时，将自动取消剩余静音帧。
- **非硬件独占说明**：本 PR 仅使应用层输出采样率对齐音源，未启用系统级声卡独占模式（Exclusive Mode）。系统音频服务（如未开启自适应采样率的混音器）仍可能进行重采样；同时软件内的音量、声像（Pan）、变速与平衡调节仍会改变采样值，因此不承诺端到端的绝对 Bit-Perfect。

## 测试与验证
- **跨平台编译**：通过 Linux、Windows、macOS 桌面端应用编译，以及 `mygo vet`、完整项目测试和音频竞态检查（Race Detector）。
- **多采样率与预热覆盖**：完成 `44.1 / 48 / 88.2 / 96 / 192 kHz` 切换测试，验证预热帧数精度、跨缓冲区边界处理、首帧保留及播放进度准确性。
- **状态机边界测试**：覆盖 40ms/250ms 延迟补偿、短暂停恢复、5 秒空闲关闭后唤醒恢复、设备开启过程中快速切歌等场景。
- **混音与音效策略测试**：验证普通音效默认不预热、冷启动不预热、中途加入音乐不重置预热、取消请求后无残留静音。
- **非桌面平台策略验证**：通过 `linux/386` 目标运行非桌面策略测试，完成 Web 音频测试编译，并通过 `go list` 确认 Web、Android、iOS 正确命中禁用桌面特性的策略文件。
- **验证范围说明**：本次自动化验证未包含移动应用完整打包、浏览器真机运行及物理 DAC 切频锁定耗时测量。完整设计说明、默认行为与测试命令详见 [桌面音频输出说明](https://github.com/FQDianYan/mygo-qyin/blob/main/docs/desktop-audio.md)。
